    🪪 How to Connect Passes to Google Sheets
    Follow these steps once — takes about 5 minutes
    1
    Create a new Google Sheet
    Go to sheets.google.com and click the big + button to create a blank spreadsheet. Give it any name you like, for example "Classroom Passes".
    2
    Open Apps Script
    Inside your new sheet, click Extensions in the top menu, then click Apps Script. A new tab will open that looks like a code editor — don't worry, you won't need to write any code!
    3
    Paste the script code
    In the editor you'll see a few lines that say function myFunction() { }. Select all of it and delete it. Then click the 📋 Copy Script Code button in Pass Settings and paste it in. Press Ctrl + S (or the 💾 save icon) to save.
    4
    Deploy it as a Web App
    Click the blue Deploy button in the top right corner, then click New deployment.

    A box will pop up. Click the small ⚙️ gear icon next to "Select type" and choose Web app.

    Then set these two things:
    • Execute as: Me
    • Who has access: Anyone

    Then click the blue Deploy button.
    5
    Authorise it
    Google will ask you to Review permissions. Click it, choose your Google account, then click Allow. This is safe — you are just giving your own spreadsheet permission to receive data.
    ⚠️ If you see a warning saying "Google hasn't verified this app" — click Advanced then Go to (your project name). This is normal for personal scripts.
    6
    Copy the Web App URL
    After authorising, a box shows your Web app URL. Copy that link — it will look something like:
    https://script.google.com/macros/s/ABC123.../exec Make sure it ends in /exec — not /dev.
    7
    Paste the URL and test it — right here
    Paste the Web App URL into the box below and click Test Connection. You should see ✅ Connected!
    ✓
    You're all set!
    From now on, every time a student checks out or back in, it will be automatically saved to your Google Sheet. Your sheet will have a tab at the bottom called Passes — click on it to see all the records.
